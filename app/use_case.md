# Databricks App — Caso de uso

La App no será una copia del dashboard.

## Objetivo

Servir como **Operations Control Center** para revisar el estado de los datos y del negocio.

## Pantallas

### 1. Pipeline Health
- último run
- registros procesados
- registros rechazados
- DQ Score
- duración

### 2. Inventory Actions
- productos CRITICAL
- tienda afectada
- stock actual
- reorder point

### 3. Data Quality
- checks fallidos
- dataset
- severidad
- incidentes abiertos

### 4. Business Detail
- drill-down de una tienda o categoría

## Regla

Dashboard = análisis.

App = operación / acción.
