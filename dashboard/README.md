# AI/BI Dashboard

El dashboard convierte Gold en una experiencia analítica para usuarios de negocio.

La versión documentada está organizada en cuatro páginas:

1. Executive Overview
2. Sales Performance
3. Inventory Risk
4. Customer Value

La especificación, datasets SQL y guion de demo se encuentran en esta carpeta.

## Filosofía

Cada visual responde una pregunta de negocio. Cuando una visualización no ayuda a explicar una decisión, se elimina.
