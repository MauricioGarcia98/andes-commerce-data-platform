# INC-20260914-001 — Order Data Quality Failure

**Severidad:** High  
**Detección:** DQ-ORD-001  

## Síntoma
187 registros incumplen una regla crítica de órdenes.

## Impacto
El dataset no puede considerarse confiable para Gold.

## Causa raíz simulada
Un upstream reenvió registros con `order_id` duplicado.

## Acción
Conservar Bronze, aislar duplicados, deduplicar usando la regla documentada, recalcular DQ, reconciliar y regenerar Gold.

## Validación
- duplicados = 0;
- DQ crítico = PASS;
- diferencia de conteos explicada;
- run de recuperación registrado.
