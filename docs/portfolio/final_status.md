## Límites declarados

- Los datos son sintéticos.
- El workspace de Databricks pertenece al usuario que ejecute el proyecto; el repositorio no incluye una ejecución productiva real.
- Unity Catalog, Jobs, AI/BI y Apps requieren configuración del workspace y permisos correspondientes.
- Las cifras mostradas en la demo provienen del dataset sintético del repositorio.

## Señal profesional buscada

El proyecto está pensado para demostrar razonamiento de consultoría junior, no seniority artificial: entender el problema, explicar trade-offs, construir una solución reproducible y saber diagnosticar fallos.
